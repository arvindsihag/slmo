# SLMO: Deployment Failure Taxonomy for Robot Systems

Companion repository for the HRI 2027 Industry White Paper:
**"When Robot Deployments Fail: A Practitioner's Taxonomy"**

## Overview
This repository provides the diagnostic framework, case encodings,
and deployment-readiness checklist described in the paper.

## Contents
- `taxonomy/` — Definitions of Stage, Locus, Mechanism, Outcome
- `cases/` — Encoded failure cases (Robo-Barista, Henn-na, Lindsey, Blue Jay)
- `checklist/` — Deployment-readiness questions for practitioners
- `coding-sheet.csv` — Cross-case evidence table
