# Stage (S)

**Definition.** The phase of the deployment lifecycle at which the
problem emerges.

## Values

| Stage | Description |
|---|---|
| Design / site preparation | Requirements, site survey, workflow mapping, capability scoping |
| Integration | Connecting the robot to existing systems, staff, and infrastructure |
| Initial operation | First weeks of live use; teething problems, expectation calibration |
| Sustained operation | Months to years of use; wear, drift, staff turnover, changing context |
| Scaling / adaptation | Extending to new sites, tasks, or user populations |

## Why stage matters

A poor integration and a system that works initially but becomes
burdensome to maintain look identical if only the eventual outcome is
recorded. Stage separates these cases and points to different
corrective actions:

- Integration-stage problems usually require interface or workflow fixes.
- Sustained-operation problems often require recovery design, maintenance planning, or staff training.
- Scaling-stage problems are dominated by economics, manufacturing, and organisational readiness.
