# Locus (L)

**Definition.** Where the failure is located — which part of the
socio-technical deployment system the problem sits in.

*Locus* is the singular form; *loci* is the plural. The word means
"place" or "category" and answers the question: *where does the
failure sit?*

## Values

| Locus | Description |
|---|---|
| Robot / technical | Hardware, software, perception, navigation, manipulation |
| Human factors | User abilities, expectations, prior experience, trust, workload |
| Physical environment | Layout, lighting, noise, weather, floor surfaces, obstacles |
| Organisation / workflow | Staff roles, hand-offs, monitoring, escalation, hidden work |
| Economic / business | Cost, ROI, manufacturing, scaling economics |
| Governance / safety | Regulation, liability, accountability, standards |

## Why locus matters

Real deployments can break down even when the robot hardware and
software operate exactly as specified. The locus dimension forces
attention beyond component faults and makes it possible to record,
for example, a failure that sits entirely in workflow or in
economics.

## Examples from the paper

- **Robo-Barista** — human, technical, social context
- **Henn-na Hotel** — human, technical, workflow
- **Lindsey** — technical, environmental, human
- **Blue Jay** — organisational, economic, technical
